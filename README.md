# 🚀 AB测试自动化分析平台

## 📌 项目简介
上传CSV文件，自动完成AB测试全流程分析（T检验、卡方检验、功效诊断、下钻分析），并一键导出Word报告。

## ✨ 核心功能
- **双检验引擎**：T检验（数值指标）+ 卡方检验（转化率）
- **多维度下钻**：自动检测辛普森悖论，发现细分人群的隐藏效应
- **实验设计诊断**：统计功效评估 + 最小样本量预估
- **数据质量校验**：SRM检验（检查分流是否均匀）
- **一键报告导出**：生成包含图表、结论和下钻结果的Word文档

## 🛠️ 技术栈
- **前端/交互**：Streamlit

- **可视化**：Matplotlib

## 📂 数据格式要求
- 必须包含三列：**分组列**（2个值，如A/B）、**数值列**（连续数字）、**转化列**（0或1）
- 可选分类列（如设备、地区），用于下钻分析
